# Share Artifacts

Publish and share your work as hosted web pages — dashboards, visualizations, React apps, reports, and HTML pages — with a shareable URL.

## What it does

This plugin connects Claude to [Bauta](https://bauta.app), a hosting service for artifacts. Works in Claude Code, Claude desktop, and Cowork. It adds two skills:

- **Publish** — Deploy content to a live URL and share it with others. Say "share this", "publish this", or "send this to someone" to get started.
- **Manage Artifacts** — List, update, roll back, and manage your published artifacts. Say "show my artifacts", "update my site", or "check analytics".

## Setup

Connect Bauta in Settings > Connectors, or visit the [Bauta connector page](https://claude.ai/directory/connectors/bauta) to add it.

## Features

- **One-step publishing** — deploy HTML or React content to a live URL instantly
- **Flexible sharing** — unlisted links, public URLs, password protection, or email-verified access
- **Email invites** — send branded invitations to specific people
- **Version history** — every update creates a new revision; roll back to any previous version
- **Live data** — bind data sources to artifacts for dashboards that stay fresh
- **Analytics** — see how many people view your published artifacts
- **Ephemeral deploys** — publish temporary content that auto-expires
- **Team features** — org management, team analytics, and audit logs on paid plans
